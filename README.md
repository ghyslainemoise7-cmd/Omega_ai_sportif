# OMEGA AI SPORTS

Premye modèl vizyèl React + Vite pou yon sit analiz espòtif.

## Kouri sou òdinatè
1. Enstale Node.js.
2. Louvri dosye pwojè a nan tèminal.
3. Kouri `npm install`.
4. Kouri `npm run dev`.

## Mete sou Vercel
1. Mete dosye sa yo nan yon repozitwa GitHub.
2. Enpòte repozitwa a nan Vercel.
3. Vercel ta dwe detekte Vite otomatikman.
4. Build command: `npm run build`
5. Output directory: `dist`

## Sa ki poko konekte
Sa se yon pwototip frontend. Li pa gen backend, baz done, otantifikasyon sekirize, verifikasyon NatCash, API match, ni modèl AI reyèl. Fòm yo se demonstrasyon sèlman. Pa sèvi ak li pou resevwa peman oswa modpas reyèl.

Pou lansman reyèl, ajoute:
- Backend ak baz done sekirize pou kont, esè 15 jou, peman ak aksè VIP.
- Hash modpas ak kontwòl aksè administratè.
- Verifikasyon manyèl peman sou sèvè, ak kòd tranzaksyon inik ki pa ka sèvi de fwa.
- API done espòtif ak sous done pou rezilta.
- Sèvis analiz AI ki bay pwobabilite, pa garanti.
